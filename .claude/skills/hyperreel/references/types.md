# Video types (pick one; borrow its shot grammar)

Categories adapted from launch-video-clone `types/` (MIT, see NOTICE.md), rewritten for the hybrid
HyperFrames + Three.js pipeline.

| Type | Looks like | Hero / layers | Signature moves |
|---|---|---|---|
| **3d-product** | a physical thing in studio light: device, product, prize wheel, package | Three.js hero with PBR + room environment; HTML callouts | macro → wide pull-back, slow orbit, exploded view, material close-ups, spin-and-land |
| **kinetic-type-into-object** | the headline is built from the hero's own parts, then the camera pulls back to reveal the object | Three.js or DOM grid of parts, one camera | one-take log zoom, parts flipping into letters, reveal of the whole |
| **ui-showcase** | the product's real interface doing a real task | captured screenshots rebuilt as DOM, optional 3D device frame | cursor-driven task, zoom to the result, count-ups, before/after |
| **editorial-collage** | magazine layout: photos, cut-outs, big type, paper/texture | DOM + images, light 3D parallax | layered parallax, wipe/cover cuts, sticker highlights |
| **abstract-3d-diagram** | an idea as moving geometry: networks, layers, flows | Three.js geometry (instanced), HTML labels | assemble from points, layer stacks separating, flow along paths |
| **campaign / offer reel** | a festival or limited-time offer with a hero object and the client's props | 3D hero + procedural props + ribbons/stickers | hero transforms per beat, prize/offer cards, count-up slam, CTA on a real photo |
| **showreel** | the maker's range in one piece: many techniques, one rhythm | rotating cast of heroes/looks, one consistent type system | match cuts on shape/color, each beat a different technique, a signature end card |

Avoid in original pieces: liquid-glass/frosted UI unless cloning a reference built that way.

## Script shape (original mode)
Biggest outcome in the first 2–3 s → no logo first → show, don't explain → proof (numbers, real names) → payoff on the
drop → CTA. 15–30 s for social; 30–45 s for a launch.

## Showreel specifics (motion designer reel)
Lead with the strongest single shot; 1 technique per 1.5–2.5 s beat (3D hero, kinetic type, particles, a transition,
a data viz, a texture/light trick); unify with one palette, one typeface and one music grid; end on a name/title card
that is itself a motion piece (e.g., the hero assembling the name). Every beat should make a viewer ask "how was that
made?".
