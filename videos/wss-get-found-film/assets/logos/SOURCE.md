# Platform logos

From "SVG Logos" by Gil Barbara (https://github.com/gilbarbara/logos), CC0-1.0, via the npm package `@iconify-json/logos`. Extracted unmodified by `tools/extract_logos.py`.

The marks are trademarks of their owners (Google, Meta, WhatsApp, Automattic/WordPress, YouTube, OpenAI, Perplexity). They are used only to name the platforms Web Spider Solutions works with; check each owner's brand guidelines before publishing, and don't imply a partnership that does not exist. Amazon and Google Business Profile marks are not in this set: drop official files in as `amazon-ads.svg` / `google-business-profile.svg` to use them.
